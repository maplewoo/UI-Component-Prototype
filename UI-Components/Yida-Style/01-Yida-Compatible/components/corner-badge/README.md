# CornerBadge（按钮角标 / 计数胶囊）

两种计数控件的合并：`corner` 变体是贴在按钮右上角的红色角标（如"保存修改 3""新建 5"）；`inline` 变体是嵌在主按钮文字后面的半透明计数胶囊（如"批量设为不适用 5"）。用于把"有多少条待处理 / 已选中"直接挂在触发按钮上。

- 解决的问题：统一"按钮 + 计数"的表达，避免每处各写一套红点/白胶囊样式，并固化"无白圈、0/禁用不渲染"等已定稿视觉规则。
- 典型场景：保存/新建/批量操作按钮上的数量提示。
- 宜搭兼容版本：是（`01-Yida-Compatible`）。普通 React + CSS。
- 当前版本：v0.3

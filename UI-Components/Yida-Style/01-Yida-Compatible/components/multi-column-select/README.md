# MultiColumnSelect（多列表格下拉选择器）

一个"像表格一样"的下拉选择器：展开时顶部有一行表头，每个选项是一行多列数据，单元格里可以是纯文本、迷你进度条（百分比）、或带色阶的日期标签。适合"客户-型号-类别"这类需要一眼对比多个指标后再选择的选择框。

- 解决的问题：普通 Select 只能显示一行文字，无法在候选项里并排展示多个属性/进度/状态色；本组件把"下拉 + 表头 + 多列富单元格"标准化。
- 典型场景：项目/组合选择、按多个维度浏览后选定一条记录。
- 宜搭兼容版本：是（`01-Yida-Compatible`）。基于 antd `Select` 的 `optionRender` + `dropdownRender`，保留宜搭 canvas 写法。
- 当前版本：v0.2

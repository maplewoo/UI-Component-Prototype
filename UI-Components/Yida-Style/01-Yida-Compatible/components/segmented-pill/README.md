# SegmentedPill（滑块式分段切换）

一个"药丸容器 + 滑动指示块"的分段切换器：选中段是蓝色滑块（白字），切换时滑块平滑位移。可选 `locked` 态：某段被禁用（灰字 + 禁止光标），点击时触发宿主回调（如"当前有未保存的修改"提示）而非切换。用于在同一区域切换 2–N 个视图/角色 Tab。

- 解决的问题：比 antd `Tabs` 更紧凑、比原生 `Segmented` 更贴合主色，且内置"锁定段 + 点击拦截"这一交互。
- 典型场景：自查/复查视图切换、任意"少量互斥视图 + 可能有脏锁"的顶栏切换。
- 宜搭兼容版本：是（`01-Yida-Compatible`）。纯 React + CSS。
- 当前版本：v0.3

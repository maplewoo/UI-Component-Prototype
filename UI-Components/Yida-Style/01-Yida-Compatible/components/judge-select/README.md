# JudgeSelect（状态判定选择器 / 只读色块）

一个"带颜色语义"的下拉选择器：收起时是一枚彩色 pill（背景/文字随选项状态色变化、右侧带下拉小箭头），展开时每个选项前有同色小方点。另附只读态 `pill`（不可点，仅显示状态色块）。用于列表格里逐行选择/展示"判定/状态"这类带语义色的单选值。

- 解决的问题：把 antd Select 做成"选中值即用状态色说话"的紧凑控件，避免每页各写一套彩色下拉 + 只读色块。
- 典型场景：表格"自查判定/复查判定"列、任何"状态单选 + 需要一眼看出当前状态色"的行内编辑。
- 宜搭兼容版本：是（`01-Yida-Compatible`）。基于 antd `Select` 的 `labelRender`/`optionRender`。
- 当前版本：v0.1

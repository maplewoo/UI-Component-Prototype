# ImagePasteUploader（剪贴板粘贴图片上传单元）

一个 112px 宽的水平居中"锚定盒"：内含一枚与附件按钮等大的上传按钮，和一排缩略图。点击/回车进入 armed 态（白底蓝字、左侧 6px 灯点呼吸闪烁、文案 `Ctrl+V`），粘贴即上传；缩略图 48×48、间隙 16、hover 右上角淡入红底白 X 删除、点击预览。支持只读态（仅缩略图、无按钮）。

- 解决的问题：把"点一下 → Ctrl+V 连贴多张 → 缩略图管理 → 全屏列拉伸不错位"这套图片录入固化为一个等宽、对齐稳定的单元。
- 典型场景：表格行内"结果图示/自查图示"列的图片上传与预览。
- 宜搭兼容版本：是（`01-Yida-Compatible`）。基于 antd `Image.PreviewGroup` + 原生剪贴板事件。
- 当前版本：v0.1

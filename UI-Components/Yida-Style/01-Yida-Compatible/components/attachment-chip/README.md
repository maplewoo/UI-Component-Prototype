# AttachmentChip（附件状态上传按钮）

一个 112×28 的单文件附件按钮，按状态变形：`上传附件`（空·蓝底白字）→ `上传中`（蓝底 + 内部淡蓝进度条，文本只显示真实百分比 `N%`）→ `已上传`（绿底白字，本次会话新写入未保存）→ `当前附件`（白底蓝字，服务器已存在）→ 只读态（白底、无删除）。点击非删除区＝预览文件，hover 时右侧划入红底白 X 删除。

- 解决的问题：把"单附件上传/展示/删除"的多态收进一枚等宽按钮，状态用颜色与文案直陈，且与图片上传按钮等宽等大、观感统一。
- 典型场景：表格行内"附件"列的逐行上传与预览。
- 宜搭兼容版本：是（`01-Yida-Compatible`）。基于 antd `Upload` 的 `beforeUpload`/`customRequest`。
- 当前版本：v0.1

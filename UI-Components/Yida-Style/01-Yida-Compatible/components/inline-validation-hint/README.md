# InlineValidationHint（行内校验状态提示）

表单/单元格字段下方的一行彩色状态提示，表达异步校验的结果：`loading`（蓝，校验中）、`pass`（绿，勾选 + 理由）、`fail`（红，`!` + 理由）、`required`（红短提示 `! 必填`）、`info`（灰，如"校验暂不可用，请人工确认"）。无内容时不渲染。

- 解决的问题：把"逻辑必填"和"异步智能校验"两类反馈统一成一套取色/图标/排版，避免各字段各写；把校验逻辑与展示解耦。
- 典型场景：textarea/输入框下方"blur 触发异步校验 → 回填结果"的反馈行。
- 宜搭兼容版本：是（`01-Yida-Compatible`）。纯 React + CSS。
- 当前版本：v0.1

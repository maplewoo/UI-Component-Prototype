# 宜搭看板 · 设计令牌（Design Tokens）

本页所有组件的最高视觉依据。规则：**组件只引用令牌变量、不写死数值**；同一语义（如判定色、主色、文字层级）全站单一定义，改一处全站同步。凡本文件规定的取值，在各组件 `SPEC.md` 中一律为 **MANDATORY**，不得页面级临时改动；如需变更，走令牌版本升级，而非局部覆盖。

来源：`Checklist检查` 页定稿沉淀（`checklist-selfcheck.canvas.jsx`）。单位 px；文字层级用半透明黑；判定色单一来源。

## 1 · 令牌块（新页面开头声明一次，组件引用变量）

```css
:root{
  --brand:#1677ff; --brand-hover:#69b1ff; --brand-bg:#e6f4ff; --brand-border:#91caff; --brand-active:#0958d9;
  --t1:rgba(0,0,0,.88); --t2:rgba(0,0,0,.65); --t3:rgba(0,0,0,.45); --t4:rgba(0,0,0,.25);
  --line:#f0f0f0; --line-strong:#d9d9d9; --page:#f2f3f5; --fill-hover:#f5f7fa; --fill:#fafafa;
  --danger:var(--j-fail); --danger-hover:#ff4d4f; --success:var(--j-pass);
  --j-pending:#eceff1; --j-pending-dot:#b0bec5; --j-pass:#19c355; --j-cond:#ffb300; --j-fail:#f44336; --j-na:#9e9e9e;
  --track:#eef0f3; --head-bg:#fafbfc;
  --r-card:8px; --r-ctrl:6px; --r-small:4px;
  --f-aux:12px; --f-body:14px; --f-sub:16px; --f-block:16px; --f-title:20px;
  --fw-regular:400; --fw-medium:500; --fw-strong:600;
  --lh-num:1.2; --lh-heading:1.3; --lh-body:1.5715;
  --h-ctrl:28px; --h-ctrl-lg:32px;
  --sh-card:0 1px 2px rgba(16,24,40,.04); --sh-pop:0 6px 16px rgba(16,24,40,.14); --sh-full:0 8px 32px rgba(0,0,0,.20);

```

## 2 · 语义速查（MANDATORY 单一来源）

- 主色 `--brand` #1677ff（强制主色，不跟随平台主题）；hover `--brand-hover`；浅底 `--brand-bg`。
- 文字层级：`--t1` 标题正文 / `--t2` 次级 / `--t3` 辅助 / `--t4` 占位与禁用。占位符必须显式取 `--t4`。
- 描边 `--line`（卡片/分隔）、`--line-strong`（控件边框）；底色 `--page` / `--fill` / `--fill-hover`(hover) / `--head-bg`(卡头=表头同色)。
- 判定状态（表格判定块、进度条、徽标、图例全部引用同一组，不得各写）：
  - 待定 块底 `--j-pending` / 点 `--j-pending-dot`（浅灰底、文字保持深色）
  - 通过 `--j-pass`｜带条件通过 `--j-cond`｜不通过 `--j-fail`（=`--danger`）｜不适用 `--j-na`
- 危险 `--danger`、成功 `--success`。

## 3 · 字号 / 字重 / 行高 / 控件高 / 圆角 / 阴影 / 层级（四档/三级，取消杂值）

- 字号：辅助 12 / 正文 14 / 卡片标题·区块标签·列头 16 / 页标题 20。禁用 13/15/10/11 杂值。
- 字重：400 控件与校验状态文字 / 500 元信息·徽标·表单小标签 / 600 标题·列头·大数字。禁用 700。
- 行高：数字 1.2 / 标题 1.3 / 正文多行 1.5715。
- 控件高：页面级按钮 32 / 表内控件·分页 28 / 输入·下拉 32。
- 圆角：卡片 8 / 控件 6 / 小元素 4。
- 阴影：卡片 `--sh-card` / 浮层 `--sh-pop` / 全屏 `--sh-full`。
- 层级：遮罩 900 < 全屏卡 950 < 弹窗抽屉 1000 < 下拉 1050 < 气泡 1070。
- 字体族：`-apple-system / PingFang SC / Microsoft YaHei`；button/input/textarea 显式 `font-family:inherit`。

## 4 · 关键组件尺寸（定稿，组件按此强制）

- 判定选择块 = 图片上传按钮 = 附件按钮：固定 **112×28**（三者等大）；控件上"带条件通过"缩为"带条件"，下拉项写全称。
- 计数红角标（保存修改/新建）：`--danger` 底白字 12/500，**18×18** 圆形（两位数自动加宽），绝对定位右上 **(-8,-8)**、无白圈、越出 8px、`pointer-events:none`；**禁用态与 0 态完全不渲染**；其余按钮用按钮内半透明白胶囊。
- 保存↔撤销 间距 **20px**（框体一致）。
- KPI / 项目级指标 tile：**宽 98**、顶部 **3px** 彩条、标签 12 / 数值 16；数字徽标色点 **8**。
- 迷你进度条高 **8px**（绿=自查 `--j-pass` / 蓝=复查 `--brand`），完成率进度条加高 **14px**、百分比放大 **20px**。
- 缩略图 **48×48** 圆角 4；图示锚定盒 **112px**（48+16+48 双格，居中，盒中点恒等于按钮中点）。
- 一级过滤器（选择项目）8 列固定 **90/90/90/140/140/140/90/90**、容器 **min-width 950**、8 列全部居中；主机厂最多 3 中文字(42px)、总成类别最多 5 字(70px)，超出 **`text-overflow:clip` 直接截断不显省略号**。
- 二级过滤器面板：圆角 6、阴影 `--sh-pop`、行高 32、左右内距 10。
- 表格：勾选列 36 / 序号列 44 居中；行内距 14 8、hover `--fill-hover`；表头 `--head-bg` + `--t2` + 14/600。
- 关键词历史：最多最近 **5** 条、去重按时间去；命中数只显示数字。

## 5 · 交互/文案铁律（定稿）

- 焦点可见 `:focus-visible`：2px `--brand` 描边 + 2px 外偏移；禁用态不给焦点环。
- 文本铁律：任何文本不得越出自身边框——放不下换行（校验）或省略/截断（元信息、KPI 标签、下拉截断列）。
- 校验状态用纯彩色文字（绿 通过 / 蓝 校验中 / 红 错误 / 灰 暂不可用）；两类校验区分：逻辑必填=短"！ 必填"，智能校验不通过=红色详细理由；通过态只写"✓ 校验通过"。
- 用词表（跨页统一）：新建Checklist · 保存修改 · 撤销修改 · 清除筛选 · 批量设为不适用 · 上传附件/当前附件/删除附件 · 图片上传 · 重新加载 · 共 N 项 · 跳至 N 页 · 完成率 · **智能校验**（不用"AI"字样） · 当前有未保存的修改。

## 6 · 组件引用约定

- 组件实现里凡本文件规定值一律写成 `var(--token, #fallback)`（fallback 即令牌字面值，供无令牌环境兜底），**禁止裸写死**。
- 组件 props 可留覆盖入口，但**默认值必须等于令牌值**；页面级随意改令牌值视为违规。
- `preview.html` 为脱离宜搭的独立演示，允许内联字面值以还原观感，但仍按令牌值取（不引入令牌块之外的新值）。
